# Zizz Interactive Mobile Games Website

Simple responsive static HTML website with 4 linked pages:

- `index.html` — Home
- `games.html` — Games
- `about.html` — About
- `contact.html` — Contact with mailto email form
- `styles.css` — Shared styling

## GitHub Pages
1. Create a GitHub repository.
2. Upload all files to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. Your site URL will be shown by GitHub Pages.

Replace `contact@zizzinteractive.com` with your real email in all HTML files.
