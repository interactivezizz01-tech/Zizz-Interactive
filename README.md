# Zizz Interactive Mobile Games Website

Simple responsive static HTML website with 5 linked pages:

- `index.html` — Home
- `games.html` — Games
- `about.html` — About
- `contact.html` — Contact with mailto email form
- `privacy.html` — Privacy Policy
- `styles.css` — Shared styling

## GitHub Pages
1. Upload all files to the repository root.
2. Open Settings → Pages.
3. Select Deploy from a branch.
4. Select `main` and `/ (root)`, then save.
5. Open the URL shown by GitHub Pages.

Replace the placeholder email addresses with your official support/privacy email before publishing.
